# Support

## How to get help

| You want to… | Go to |
|---|---|
| Ask a question or discuss an idea | [GitHub Discussions](../../discussions) |
| Report a bug | [Open a bug report](../../issues/new?template=bug_report.md) |
| Request a feature | [Open a feature request](../../issues/new?template=feature_request.md) |
| Report a security vulnerability | Follow [SECURITY.md](SECURITY.md); do **not** open a public issue |

Before opening an issue, please search existing issues and discussions.

## Support policy

This is a community-maintained open-source project. Support is provided on a best-effort basis by
maintainers and contributors; there is no service-level agreement.

If you use a hosted FaithTech Community site and need help with your account, contact the
administrators of that site rather than this repository.
