# Add an event to your calendar

## opening: Opening
In this video you take an event into your own calendar. The app is real; the server is a local stand-in, and the people and events are made up.

## member-download: Add to calendar
On an event page, Add to calendar downloads a calendar file named after the event. Open it in any calendar app.

## public-download: From the public page
Public event pages offer the same file, so guests can add the event too. The joining link of an online event is not included.

## cancelled-update: When the event changes
If the event is later changed or cancelled, the button becomes Update your calendar. The new file replaces the old one in your calendar, and a cancelled event is marked as cancelled.

## closing: Summary
That is calendar export: one button, a standard file, and updates that replace the old entry.
