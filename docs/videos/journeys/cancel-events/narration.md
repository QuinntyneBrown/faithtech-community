# Cancel an event

## opening: Opening
In this video a City Lead cancels an event and tells everyone why. The app is real; the server is a local stand-in, and the people and events are made up.

## dialog: Cancel event
On the event page, Cancel event opens a dialog. It tells you how many people will be emailed, and how many of them also get an in-app notification.

## empty-reason: A reason is required
You cannot cancel without a reason, because people deserve to know why. The dialog asks you to tell attendees.

## reason: Explain and confirm
Write a short message, then confirm. Keep event is always there if you change your mind.

## cancelled: Cancelled
The event page now says it was cancelled, by whom, when, and why. Edit, RSVP and Cancel event are gone.

## public: The public page
The public page agrees: the event is cancelled and no longer takes RSVPs.

## closing: Summary
That is cancelling an event: a required reason, everyone told, and no more RSVPs.
