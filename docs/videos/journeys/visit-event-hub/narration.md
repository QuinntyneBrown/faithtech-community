# Visit an event hub

## opening: Opening
In this video a visitor opens a published event hub on the night of the event. The app is real; the server is a local stand-in, and the people and events are made up.

## card: The event page
Once a hub is published, the public event page gets an Event hub card. RSVP and the calendar download stay right here.

## hub: The hub page
Open the event hub, and everything for the night is on one page. No account needed, and no preview banner. It's just the page.

## now: Happening now
The agenda knows the time. What's done is greyed out, what's on now is highlighted, and the next session says Up next.

## moves: It moves on
Leave the page open, and it keeps up by itself. When code freeze starts, the highlight moves, and screen readers hear it once.

## rest: Everything else
Below the agenda are the venue, giving and what's coming up next. Only what the lead finished and chose to show.

## members: Members only
A hub on a members-only event doesn't open for visitors. They're asked to sign in instead.

## signed-in: Signed in
Sign in, and you're straight back on the hub.

## closing: Summary
That's visiting an event hub: one link for the whole day, an agenda that keeps up, and members-only hubs kept for members.
