# Connect by QR code

## opening: Opening
In this video a city lead meets someone new at an event and connects with them using a QR code. The app is real; the server is a local stand-in, and the people are made up.

## invites: My QR code
On the Invites page, leads have a My QR code button. It's not an invite: it's one code that belongs to the lead and never expires.

## my-code: The code
Here's Grace's code, with the link it opens right underneath. It's the same code every time, until she chooses to make a new one, which retires the old link.

## download: Download
Download saves the code as a picture, to print on a name badge or a table card.

## scan: Someone scans it
Now a visitor scans the code with their phone. The page says who they're connecting with, Grace, a City Lead in Toronto, and what connecting does.

## sign-up: Sign up
They create an account right there: name, email and a passphrase, with the same rules as the normal sign-up. Then they're asked to check their email.

## verified: Verify
They open the link in that email, and they're in.

## contact: A new contact
And when Grace looks at her contacts, the new member is already there, linked to their profile, with no typing on her part.

## closing: Summary
That's connecting by QR code: one code that never expires, scan, sign up and verify, and the new member is already the lead's contact.
