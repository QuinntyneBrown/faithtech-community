# Edit hub templates

## opening: Opening
In this video an administrator edits the organisation's event hub templates in Organisation settings. The app is real; the server is a local stand-in, and the people and events are made up.

## tab: Hub templates
A fifth settings tab lists the templates leads are offered when they create a hub, in order, with how many sections each shows.

## add: Add a template
Add a template for prayer nights, with a line that says what it suits.

## open: Its sections
Open it. It starts with the seven core sections shown and no text yet.

## sections: Choose sections
Choose its sections. Tick Worship, and untick the submission links a prayer night doesn't need.

## default: Default text
Each section's default is written with the same wizard leads use on a hub. The wizard says it's editing the template.

## saved: Saved
Save it. New hubs started from Prayer night will use it; hubs already started keep what they have.

## offered: Offered to leads
On the next event, a lead creating a hub is offered Prayer night, with Worship already ticked.

## closing: Summary
That's editing hub templates: set up once, in settings, and every new hub starts closer to done.
