# Event list and filters

## opening: Opening
In this video you browse the events list and narrow it down with filters. The app is real; the server is a local stand-in, and the events are made up.

## list: Upcoming events
The list opens on upcoming events, soonest first. Each one shows its date, city, where it happens, how many people are going, and whether it is public. Leads also see a New event button.

## cancelled: Cancelled events
A cancelled event stays on the list, clearly marked as cancelled, so nobody turns up by mistake.

## past: Past events
The Past filter switches to events that have already happened.

## chips: type and online
The Type filter offers the organisation’s event types, so Hackathon shows only hackathons, and Online shows only events you can join from home. Choosing a chip replaces the one before it.

## city: Pick a city
Go back to Upcoming and choose a city, such as Toronto, to see only events there.

## empty: Nothing matches
When a combination has no events, you get a plain message saying so, and one button to show all cities again.

## closing: Summary
That is the events list: upcoming first, cancelled events marked, and quick filters by time, type and city.
