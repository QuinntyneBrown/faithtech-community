# Work items

## opening: Opening
In this video you are a team member working through a story in an agile workspace. The app is real; the server is a local stand-in, and the people are made up.

## story: A story and where it fits
The story page shows its description, its story points, and where it sits: under an epic, which in turn sits under an initiative.

## tasks: Tick off tasks
Below the description are the story's tasks, with a count of how many are done. Tick Edit six briefs and the count catches up straight away.

## add-task: Add a task
Need another step? Type it into the new task box and add it. The count updates, and the task is there for everyone.

## comment: Comment
Further down, write a comment and post it. It appears at the top with your name, and the comment count goes up.

## edit: Edit the details
Edit opens a dialog for the title, assignee, story points and description. Hand the story to Ruth and raise it to thirteen points.

## status: Move it on
Finally, change the status to Done. A message confirms the move.

## closing: Summary
That is working a story: tasks, comments, details and status, all on one page.
