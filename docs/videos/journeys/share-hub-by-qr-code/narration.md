# Share a hub by QR code

## opening: Opening
In this video a city lead puts an event hub in front of a room with a QR code: on the projector before the talks, and on a sign at the welcome table. The app is real; the server is a local stand-in, and the people and events are made up.

## home: Share
On the hub home, the Your hub card has a Share button, between Preview and Publish.

## draft: A draft says so
The hub is still a draft, so the Share dialog says who the code works for: until it's published, only people who manage event hubs can open it. Everyone else would be told it isn't available.

## publish: Publish
So publish it first. Now anyone can open the hub.

## share: The QR code
Share again. There's the QR code, and the hub's link right under it, with Copy link for a message. The code opens exactly that link.

## full: Full screen
Show full screen. The code fills the screen for the projector, with the event's name, the link as text for anyone at the back, and a reminder that Escape closes it.

## escape: Back with Escape
Press Escape, and you're back in the dialog, right where you were.

## download: Download
Download image saves the code as a picture, named after the event, ready to print for the welcome table.

## closing: Summary
That's sharing a hub by QR code: Share on the hub home, full screen for the projector, and an image to print.
