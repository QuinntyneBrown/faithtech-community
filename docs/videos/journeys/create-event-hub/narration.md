# Create an event hub

## opening: Opening
In this video a City Lead starts an event hub, the one page attendees keep open on the day. The app is real; the server is a local stand-in, and the people and events are made up.

## event-page: The event page
On an event's page, people who manage event hubs see a new button: Create event hub.

## event-step: Which event
The wizard asks one question at a time. First, which event is this hub for? The name, date, place and RSVP link come straight from the event, so the hub never goes out of step with it.

## starting-point: Starting point
Next, choose how to start. Blank is ready today; templates for hackathons, meetups and workshops are on the way. By now the hub already exists as a draft, so nothing is lost if you stop.

## sections: Sections
Then pick what the hub should include. Each section says in plain words what visitors will see. This event has no giving appeal, so Giving is unticked.

## done: Done
That's it. The hub is a draft that only people who manage hubs can see. You can fill it in now, or save and finish later from any step.

## hub-home: The hub home
The hub home shows the draft status, the link visitors will use once it's published, and a checklist. Three of six sections are ready already, and the rest say what they still need.

## closing: Summary
That's starting an event hub: four short steps, saved as you go, with a checklist showing exactly what's left.
