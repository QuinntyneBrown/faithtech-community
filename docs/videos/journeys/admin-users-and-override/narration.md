# Admin users and profile override

## opening: Opening
In this video you act as a System Admin and look after every account in the community. The app is real; the server is a local stand-in, and the people are made up.

## admin-link: The Admin area
Only System Admins see the Admin link in the top bar. It opens the list of every user account.

## all-users: Everyone, with status
Each row shows a person's roles and their status: active, suspended, or unverified because they have not confirmed their email yet.

## search: Find someone
Type a name or an email address and press Enter to narrow the list. If nothing matches, you are told so, and clearing the search brings everyone back.

## open-profile: Open a profile
A name in the list takes you to that person's profile, where System Admins see an Edit profile button that other members never get.

## override: Edit on their behalf
The editor says plainly that you are editing someone else's profile. You change their bio and save, and the change is written to the audit log.

## closing: Summary
That is the admin user list: every account with its roles and status, quick search, and the power to correct any profile, with every change on record.
