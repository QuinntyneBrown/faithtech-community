# Fill in hub sections

## opening: Opening
In this video a City Lead fills in the event hub they started, one section at a time. The app is real; the server is a local stand-in, and the people and events are made up.

## checklist: The checklist
The hub home lists every section with what it still needs. Each one opens its own short wizard.

## hero: Hero
The hero reads the event's name, date and place on its own. The only thing to add is an optional subtitle.

## hero-saved: Saved
Save, and the checklist updates straight away.

## agenda-paste: Paste a schedule
For the agenda, you can add rows one at a time, or paste the schedule you already have. The app reads each line's time within the event's hours, and lists any line it couldn't read, so nothing is added by surprise.

## agenda-rows: The rows
The rows go in by time. Drag them, or use the arrow buttons, to change the order, and edit or remove any row.

## agenda-review: Review
Next saves the rows and shows the agenda exactly as visitors will see it.

## agenda-saved: Saved
Save, and the agenda is ready.

## venue: Venue
The venue comes from the event, with a map link built from it. Add directions, like which door to use.

## people: People
For people, search the organisation's members by name and say how each one is helping: speaker, mentor or judge. The hub always shows a member's current name and photo.

## guest: A guest
Someone who isn't a member can be added as a guest, with a line about them. Guests appear on this hub only, and never get a profile.

## people-review: Review
The review groups everyone as the hub will: speakers, mentors and judges.

## links: Submission and feedback
Then the links teams need on the day. Links must be secure, and the code freeze is picked from the agenda, so the two always agree.

## preview: Preview
Any section can be previewed from its menu, as visitors will see it.

## closing: Summary
That's filling in a hub: one short wizard per section, saved as you go, with a preview of each.
