# Create and edit events

## opening: Opening
In this video you publish an event and then change it, the way an Event Lead or City Lead does. The app is real; the server is a local stand-in, and the people and events are made up.

## new-event: New event
From the Events list, the New event button opens a blank form. Only leads with an event role see this button.

## errors: Fix before publishing
If you publish too early, the form lists what needs fixing, and each field explains its own problem. Nothing is sent until the form is complete.

## details: Fill in the details
Give the event a title, a type, a description, and start and end times. Add a city and a venue address, choose who can see it, and set a capacity if you want a limit. Then press Publish event.

## saved: Published
The event is saved and you land on its page, with every detail you entered. Leads also get a Check in button here for the day itself.

## edit: Edit the event
Edit takes you back to the same form with everything filled in. Here you move the venue and save. Everyone who already RSVPed gets a notification about the change.

## closing: Summary
That is creating and editing events: a clear form, helpful errors, and attendees who are told when something changes.
