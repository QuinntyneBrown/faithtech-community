Typography

One rounded system face, a nine-step scale in rem and twelve role shorthands, tuned so leads can scan a partner board and members can read an announcement comfortably.

Overview

FaithTech Community uses the system's rounded face (SF Pro Rounded on Apple devices, Nunito or the platform UI font elsewhere), inherited from Shelfie unchanged: warm enough for a community site, clear in dense screens such as the partner Kanban and the people table, and free to load. One family does both display and body; the monospace face is only for audit-log timestamps and IDs. Sizes come from a fixed scale in rem, so the text grows with the browser's font setting.

  • Set text with a role (font: var(--text-body)), not with loose sizes and weights.
  • Body text is 16px and never smaller than 12px; announcement bodies and contact notes use the relaxed line height.
  • Headings use text-wrap: balance; paragraphs use text-wrap: pretty and stop at the measure.

Measure and responsive type

  • Measure: paragraphs stop at --layout-measure (65 characters). Empty-state text stops at 36 characters so “Start your partner pipeline” and its hint read as one or two short lines.
  • Fixed steps, no viewport units. Type does not scale with the window, so browser zoom and the user's font size always win. The one responsive change is the dialog title, which is --text-h4 on a phone sheet and --text-h3 from 640px.
  • Numbers that change in place (pipeline stats, sprint points, the bell’s unread count, RSVP counts such as “34 going”) use font-variant-numeric: tabular-nums so they do not jitter.
  • Long titles wrap; they truncate with an ellipsis and a title only in one-line rows such as Kanban card meta and .table td.truncate in the people and audit-log tables.

Usage

  • One <h1> per page and headings in order; pick the role for its look, the element for its level (the home page’s “Coming up” card title is an <h2> set in --text-h4).
  • Uppercase only through --text-overline with --letter-spacing-wide; never type copy in capitals.
  • Do not set font sizes in px or add steps between the scale's steps. If a size is missing, the design is asking for a new role; raise it.
  • A heading set in --text-h4 carries the role as a class: .card__title for a card's own title, .section-title for a header row, page section or danger zone, .dialog__title in a dialog; never an inline font. Centred text (an auth page's <h1> and footer links) takes the .text-center utility, never an inline text-align.

Accessibility

  • Resize text (1.4.4): all sizes are rem; pages work at 200% zoom with no loss.
  • Text spacing (1.4.12): nothing clips when line height is 1.5×, paragraph spacing 2×, letter spacing 0.12em and word spacing 0.16em; containers grow instead of fixing heights.
  • Contrast: body and label text use default or muted colour (4.5:1 or more); large text (24px, or 18.7px bold) may use 3:1 but none currently needs to.
  • Minimum size: 12px for captions and badges only, never for something a member has to act on.
