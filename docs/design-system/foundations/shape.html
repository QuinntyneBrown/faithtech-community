Foundation · Shape

Shape

Soft corners scaled to the object, two border widths, and the fixed sizes for initials avatars.

WCAG 2.2 AAFoundation
  • Overview

  • Border widths

Overview

FaithTech Community keeps the soft shape inherited from Shelfie: 12px corners on fields, alerts and toasts, 24px on cards, Kanban columns, tables and dialogs, 32px on the top of a bottom sheet, and full pills for buttons, role badges, filter chips and avatars. One radius per size keeps the people, events and partner screens from looking random. This page also holds the fixed avatar sizes.

RadiusUse it for
--radius-xsCheckboxes, documentation swatches
--radius-smDate badges in compact lists, menu items, skeleton lines, close buttons
--radius-mdText fields, selects, menus, alerts, toasts, the event date badge, private-note wells, planning poker estimate cards
--radius-lgCards, hero, tables, dialogs from 640px, Kanban columns and partner cards, the notification panel, logo tile
--radius-xlTop corners of a bottom sheet (dialogs under 640px), the public event hero
--radius-fullButtons (pills), the floating top bar, role and count badges, filter chips, avatars, swatches and progress bars

Rule of thumb: the bigger the object, the bigger the radius, and a child's radius is never larger than its parent's. A 44px field gets 12px; a button or a 24px badge is a pill; a card gets 24px so the 12px date badge inside an event card never looks rounder than its parent.

Border widths

--border-width-hairline
--border-width-thick
  • Hairline (1px) for every edge: cards, fields, dividers, list rows, buttons.
  • Thick (2px) for edges that carry state: the pressed chip and selected estimate card, the button spinner, the toast timer, the hover ring on an avatar button and a hovered link's underline.
  • The focus ring has its own width, documented in Accessibility.

Avatar and media sizes

GO SM ML GO
Avatar sm 32px (top bar, people and member tables, Kanban cards), md 40px (lists, notification rows), lg 56px (inherited; no FaithTech mock uses it yet), xl 64px (profile header).

The --size-cover-* tokens are inherited from Shelfie for 2:3 media tiles (44, 80, 120 and 160px). No FaithTech Community mock uses them yet; profile photos and event images use the photo components instead. Keep them until a FaithTech screen needs a fixed media tile, or remove them in a token clean-up.

Usage

  • Use the radius token for the component's size; never mix radii inside one component (the bottom sheet is the one exception: rounded top, square bottom against the screen edge).
  • Never type border-radius: 50% or 9999px; use --radius-full.
  • Never set 1px or 2px borders by hand (drift D12); use the border-width tokens.
  • Avatars come in the four sizes above only; never size an avatar with a raw width.
