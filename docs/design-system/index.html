Design system

FaithTech Community design system

FaithTech Community is where staff, city leads, volunteers, builders, attendees and partners find each other, run events and keep the work moving. This system writes down every visual and interaction decision the mocks already make, so every screen built from the Angular components library is consistent and accessible in both themes.

How to use

In the Angular app

  1. Load tokens/tokens.css first, then assets/components.css. Do not copy values out of them.
  2. Build each component once in the components library with the class names and attributes from its page here. States come from real attributes (disabled, aria-invalid, aria-pressed, aria-current, aria-selected, aria-busy); data-state exists only so these pages can show a state without a pointer.
  3. Theme with data-theme="light|dark" on <html>; with neither, the OS preference applies.
  4. Need a value in TypeScript or the API (email templates)? Read tokens/tokens.json (W3C DTCG format; dark values under $extensions).

Changing the system

Change a brand hue in the primitives, a meaning in the semantic tier, a component look in its component tokens. When FaithTech brand colours are supplied, replace the violet ramp in tokens.css and re-run the contrast check. After any page change run the structure check.
