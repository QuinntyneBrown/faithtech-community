# Demo photo credits

These photos are for demo mocks only.

## Portraits (`people/`)

Every portrait in `people/` is AI-generated by [thispersondoesnotexist.com](https://thispersondoesnotexist.com/) (StyleGAN). None of them shows a real person, and each is assigned to a fictional member by name (`grace-okonkwo.jpg` is Grace Okonkwo, and so on).
