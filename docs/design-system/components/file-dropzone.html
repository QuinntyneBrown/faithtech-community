File drop zone

A dashed target that takes files by drag and drop or opens the file picker on click, Enter or Space. It states the limits before anyone chooses a file.

WCAG 2.2 AAStatus: newft-file-dropzone

Overview

Use the drop zone wherever a member adds files: the Add a resource dialog and Replace file in the Edit dialog. It is a <label> that wraps a visually hidden native file input, so it needs no script to be keyboard and screen-reader operable; drag and drop is an enhancement on top. Chosen files are shown as file rows above it, and the zone shrinks its title to "Add more files". Profile photos keep the picture list.

  • Empty: "Drop files here or choose files" before anything is chosen.
  • Add more: "Add more files" under the rows of a batch.
  • Single ([multiple]="false"): Replace file takes exactly one file.

Anatomy

  1. Icon tileUpload icon in a 56px .icon-tile (--size-avatar-lg), --color-fg-accent.
  2. Title--text-label: "Drop files here or choose files" or "Add more files".
  3. Limits line--text-body-sm, --color-fg-muted, at most 40ch; referenced by the input's aria-describedby.
  4. Zone2px dashed --color-border-strong, --radius-lg, --color-bg-subtle, --space-8 block padding. Wraps the hidden <input type="file">.

Sizes

One size. The zone fills its container; inside a dialog it is the dialog body's width. Block padding is --space-8, side padding --space-4.

States

Pointer, focus and drag states are forced with data-state for documentation; real pages get them from :hover, :focus-within and the component's drag handlers.

Disabled (busy)

Both themes

  • Drag over: accent border and accent tint while files are held over the zone.
  • Invalid: danger border; the field error below names the file and the allowed types, and the input carries aria-invalid.
  • Disabled: while a batch uploads the zone is disabled with the rest of the form.
  • Files over the limit of 20 are refused with the limits line; nothing is uploaded until the form is submitted.

Responsive behaviour

  • The zone is fluid and never scrolls sideways; the limits line wraps.
  • On touch devices there is nothing to drop on; the zone is a large target that opens the system file picker.
  • At XS inside a full-screen dialog it keeps --space-8 block padding so it stays an easy target.

Theming

Reads --color-bg-subtle, --color-border-strong, --color-fg-muted, --color-fg-accent; drag over reads --color-accent and --color-accent-subtle; invalid reads --color-danger-solid. All semantic, so both themes come for free.

Accessibility

Role and pattern

A native <label> wrapping a visually hidden <input type="file">. The accessible name is the label's text; the limits line is the description. No ARIA role is added.

Keyboard

KeyAction
TabFocuses the hidden input; the zone shows the focus ring through :focus-within.
Enter / SpaceOpens the system file picker.

Focus

2px --color-focus-ring outline with 2px offset around the whole zone. After files are chosen focus stays on the input; the new rows are announced through the dialog's polite status ("6 files").

Drag and drop

Dragging is never the only way: every drop has a keyboard equivalent (WCAG 2.5.7 Dragging Movements).

Content

  • Title: "Drop files here or choose files"; once files are chosen, "Add more files".
  • The limits line names the count, the size and every allowed type, in capitals: "Up to 20 files, 100 MB each. PPTX, PPT, …".
  • A refusal names the file, the allowed types and the next step: "… For longer video, add a link instead."

Code

<ft-file-dropzone
  title="Drop files here or choose files"
  [multiple]="true"
  accept=".pptx,.ppt,.key,.pdf,.docx,.doc,.xlsx,.csv,.png,.jpg,.svg,.gif,.webp,.mp4,.zip"
  help="Up to 20 files, 100 MB each. PPTX, PPT, KEY, PDF, …"
  [error]="fileError()"
  [disabled]="busy()"
  (filesChosen)="add($event)" />
Class / attribute / inputEffect
.dropzoneThe label-shaped zone.
.dropzone__title / .dropzone__textTitle and limits line.
data-state="hover|focus|dragover|invalid"Documentation; dragover is set by the component while files are held over it.
[multiple]Many files (default) or one (Replace file).
acceptHint for the picker only; the feature still checks every file, and the server checks again.
(filesChosen)Emits a File[] from a drop or the picker; the zone never uploads or validates by itself.
