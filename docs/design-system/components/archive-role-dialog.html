Archive role dialog

Confirm archiving a role; when the API refuses with 409 the reason is shown inside the dialog and only Close is offered.

WCAG 2.2 AAStatus: designed, not builtCDK Dialog

Overview

A destructive confirmation for one role. Archiving is refused while members hold the role, while a grant rule, share audience or announcement audience names it, and when it would leave no administrator; the dialog shows that 409 reason as a danger alert in place of the confirmation and swaps the footer for Close.

Anatomy

  1. HeaderDanger archive icon, “Archive {role}?” and what archiving does.
  2. BodyWhat uses the role, or the refusal.
  3. FooterCancel and a danger Archive role.

Variants

Archive Mentor?

It leaves every role picker. Its history stays in the audit log.

No one holds Mentor and nothing uses it.

Default: nothing uses the role.

Archive Volunteer?

It leaves every role picker.

Can’t archive Volunteer
18 members hold this role. Remove it from them first.
Refused: members hold the role (409).

Sizes

Not applicable. A bottom sheet below 40rem and a centred panel above, as every dialog.

States

  • In use: “City Lead’s grant rules and the announcement audience “Hackathon builders” still use this role. Remove it from them first.”
  • Busy: “Archiving…”.
  • Failed: “Role not archived”, “Try again”.
  • Success: toast “{role} archived”.

Responsive behaviour

  • Below 40rem it is a bottom sheet with the footer pinned; the body scrolls.
  • From 40rem it is a centred panel; see Dialog.

Theming

Raised surface --color-bg-surface-raised on the backdrop in both themes, as every dialog.

Accessibility

Role and pattern

WAI-ARIA modal dialog through Angular CDK Dialog: focus trapped, the page behind inert, Esc closes unless busy, focus returns to the button that opened it.

KeyAction
TabMoves through fields, checkboxes and footer buttons.
EscCloses without saving (not while busy).
Enter on the primary buttonSaves.

Content

  • Refusals say what to do next: “Remove it from them first.”

Do and don't

Tokens

The dialog tokens.

Code

In Angular: <ft-archive-role-dialog> (ArchiveRoleDialogComponent, data: role, submit), opened through DialogService (ADR 0005). Its submit callback resolves to null on success or to a message the dialog shows (a 400 field error, a 403 or 409 reason, or the failure with Try again).
