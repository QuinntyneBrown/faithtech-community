Component · Data display

Stat

A label over a large value, for numbers a lead checks at a glance: how many partners sit in Lead, In funnel and Confirmed, or how many sprint points are done.

Overview

Use stats in a row inside a card to summarise something the page links to. The Home partner pipeline card shows three counts and an "Open board" link; the sprint strip on the board shows the goal, completed points and end date.

A stat is read-only and never a link on its own. A count attached to a heading or nav item is a badge; a set of facts with longer values (location, capacity, organiser) is a description list.

Anatomy

  1. Label.stat__label, --text-label in --color-fg-muted. Comes first in the source so it is read first.
  2. Value.stat__value, --text-h2 with tabular numerals so a row of counts lines up.

Sizes

One size for numbers: --text-h2. Sentence values (sprint goal) and dates step down to body semibold and --text-h4 so they do not shout.

States

Not interactive, so there is no hover, focus or disabled state. Data states:

  • Loading: the card shows a skeleton block where the values go.
  • Zero: shown as "0", not hidden. An empty pipeline reads Lead 0, In funnel 0, Confirmed 0.
  • Error: the card shows an inline message instead of the row, never a dash that looks like a number.

Responsive behaviour

  • The row is a .cluster, so stats wrap onto a new line on narrow screens instead of shrinking.
  • On a 360px phone the sprint goal takes its own line and points and end date share the next.

Theming

The label reads --color-fg-muted; the value inherits --color-fg-default. Both swap per theme.

Accessibility

Role and pattern

Plain text in source order: label then value, read as "In funnel 3". No role is needed; the surrounding card has a heading ("Partner pipeline") that names the set.

Keyboard and focus

Not focusable. The card's link ("Open board") is the action.

Motion

None. Values do not count up.

Content

  • Labels are the name of the thing counted, sentence case: "In funnel", "Completed points".
  • Write ratios as "6 of 24", not "6/24" or "25%".
  • Dates use the house format, "Fri 31 Oct".
  • Three or four stats per row at most.
