Skip link

The first thing a keyboard reaches on every page. It stays out of sight until it has focus, then lets the person jump straight past the top bar (up to eight nav links, search, the bell and the avatar) to the content.

Overview

Every FaithTech Community page, signed in or not (including the public event page and the auth pages), starts with <a class="skip-link" href="#main">Skip to content</a> as the first element in <body>, and has a <main id="main"> for it to land on. It meets WCAG 2.4.1 (bypass blocks). This page has one too: press Tab from the address bar to see it.

Anatomy

  1. ContainerRaised surface, --radius-md, --shadow-3, positioned --space-4 from the top left when focused, above everything (--z-tooltip).
  2. Label"Skip to content" in --color-fg-default, no underline.

Variants

One link, one target (#main), on every page.

Sizes

One size: body text with --space-2 × --space-4 padding.

States

Two states. At rest it sits above the top of the viewport (top: calc(-1 * --space-24)); on :focus-visible it slides to --space-4. The focused state is forced here with data-state="focus".

  • Focus shows the link and the shared focus ring together. It is the only state that appears; there is no hover state because a pointer cannot reach it.
  • Activated: the browser moves to #main; scroll-padding-top keeps the heading clear of the sticky top bar.

Responsive behaviour

  • Same at every width: --space-4 from the top left, over the top bar.
  • Hidden in print with the top bar and tab bar.

Theming

Reads --color-bg-surface-raised, --color-fg-default and --shadow-3. The raised surface is lighter than the top bar in the dark theme, so the link still stands out when it lands on it.

Accessibility

Role and pattern

A native link (<a href="#main">) to the <main> landmark. No ARIA. It is moved off screen, never hidden with display: none or visibility: hidden, so it stays in the tab order.

Keyboard

KeyAction
Tab (first press on a page)Focuses the skip link and shows it.
EnterJumps to #main; the next Tab goes to the first control in the content.
Tab againHides it and moves on to the top bar brand.

Focus

The shared 2px --color-focus-ring with 2px offset. Dialog mocks move focus into the dialog (its first field or its safe action), so the skip link is not part of the dialog flow; the dialog is the content.

Labelling

"Skip to content" is the name. Do not add aria-label.

Contrast

Label on raised surface
Focus ring on raised surface

Motion

It slides into place over --duration-fast; reduced motion zeroes the duration so it simply appears.

Touch

Not used by touch; it only appears on keyboard focus. Its padded box still exceeds the 24px minimum for switch and keyboard-emulating devices.

Content

  • Always "Skip to content". Same words on every page.
