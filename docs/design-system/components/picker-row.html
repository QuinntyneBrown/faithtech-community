Picker row

One choice in a choose-from-list dialog, such as Choose from Resources: a radio or a checkbox, the item’s thumbnail (or an icon tile when it has none) and two lines of text, the title and a muted meta line. The whole row is the label.

Overview

Use picker rows when a person picks one or several existing items, each recognisable by a picture and a title, inside a dialog.

  • In use: dialogs/hub-resource-picker, opened from the Parking (one image, radios) and Slides (a PDF or images, checkboxes) wizards.
  • Rows sit in a list on a flush card, under a search field.
  • For short text-only choices, use a radio group or checkbox group.

Anatomy

  1. ControlA native radio (pick one) or checkbox (pick several), drawn like the radio and checkbox.
  2. ThumbnailAn image icon tile (.icon-tile--image); without a thumbnail, an icon tile with the document icon. Decorative.
  3. Text.choice__text: the title in strong body text over the meta line in small muted text.

Variants

Radio (pick one)

The Parking wizard picks one map image.

Checkbox (pick several)

The Slides wizard picks a PDF or several images, added in the order they are ticked. The second row has no thumbnail, so it shows the document icon tile. In Angular the checkbox is a square box with a check mark, as in the checkbox group.

Sizes

One size: the row is at least the 44px target tall, with a 40px tile; rows pad 12px by 16px.

States

StateLook
DefaultEmpty control on --color-bg-surface, --color-border-strong edge.
HoverThe control’s edge darkens to --color-fg-muted.
FocusFocus ring on the control.
Checked--color-accent fill with a dot (radio) or a check mark (checkbox).

The dialog owns the list’s loading, empty and failed states (hub-resource-picker/loading, empty, failed).

Responsive behaviour

The text takes the space left of the tile and wraps; the title breaks long words so the row never scrolls sideways.

Theming

The control and tile read the same tokens as the radio, checkbox and icon tile, so both themes follow. Thumbnails are never tinted.

Accessibility

  • A native input wrapped by its label: the accessible name is the title and the meta line, and clicking anywhere on the row toggles it.
  • Radios share one name, so the arrow keys move between them and one Tab stop holds the group; checkboxes are each a Tab stop.
  • The tile is aria-hidden; the title names the item.
KeyAction
SpaceChecks the row (toggles a checkbox).
↑ / ↓ on a radioMoves to and picks the previous or next row.

Content

  • Title: the item’s title as written.
  • Meta: type, size or length, owner and date, joined by “ · ”: “PDF · 52 pages · Grace Okonkwo · Wed 21 Oct”.

Do and don't

Tokens

PartToken
Control edge / checked fill--color-border-strong / --color-accent
Check mark and dot--color-fg-on-accent
Meta line--text-body-sm, --color-fg-muted
Row height--target-min
Gaps--space-3 / --space-0-5

Code

<ft-list label="Resources">
  @for (r of resources(); track r.id) {
    <ft-picker-row type="checkbox" name="resources" [value]="r.id" [checked]="picked(r.id)"
      [thumbnailSrc]="r.thumbnailUrl" [title]="r.title" [meta]="r.meta" (changed)="toggle(r.id, $event)" />
  }
</ft-list>
Input / outputEffect
type'radio' (default) or 'checkbox'.
name, value, checkedThe native input’s name, value and checked state.
thumbnailSrcThe thumbnail; without one the row shows an icon tile (icon, default document).
title, metaThe two lines of text; they label the input.
changedEmits the new checked state when the person changes it.
