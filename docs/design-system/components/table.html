Component · Data display

Table

Rows and columns for records people compare or audit. The System Admin audit log is the reference: when, who and what for every admin action, in a framed, scrollable table. Admin users, People and roles, and closed sprints use the same table.

Overview

Use a table when every row has the same fields and readers scan or compare a column: timestamps in the audit log, status on Admin users, roles and city on People, points per closed sprint.

  • Use a list when each row is a name and one line of context.
  • The audit log is read-only; Admin users and People add a trailing action column (Suspend, Add a role).
  • In Angular, use <ft-table> from the components library; it renders a native <table>.

Anatomy

  1. Header rowth scope="col" on --color-bg-surface-sunken, muted label text, sticky while the frame scrolls.
  2. Caption<caption class="visually-hidden"> naming the table ("Audit log").
  3. Cells--text-body-sm; timestamps in .mono so they line up.
  4. Frame (.table-wrap)Hairline border, --radius-lg, horizontal scroll on narrow screens.

Responsive behaviour

  • The table keeps its columns; below its natural width the .table-wrap scrolls horizontally inside the page, never the page itself.
  • The header stays sticky while the frame scrolls.
  • Long "What" text wraps; timestamps do not.

Theming

The header, hover and frame read surface and border tokens, so the table follows the theme with no table-specific tokens.

Accessibility

Role and pattern

A native <table> with <caption> and th scope="col", so each cell is announced with its column ("Who, Priya Shah"). Never use a grid of divs.

Keyboard

KeyAction
TabMoves through links and buttons in cells; the table itself is not a tab stop.
Shift + scroll / trackpadScrolls a wide table inside its frame.

Focus

The shared focus ring on links and buttons in cells.

Labelling

An action column has a visually hidden header ("Actions"), and each button names its row with a visually hidden object: Suspend<span class="visually-hidden"> Grace Okonkwo</span>.

Content

  • Column headers are one or two words: When, Who, What, Status.
  • Audit timestamps are absolute, 24-hour, 2026-10-21 10:05, so exports sort; elsewhere use "Mon 20 Oct".
  • Audit "What" is a past-tense sentence naming the target and, for private contacts, the owner: "Opened private contact “Ben Carter” owned by Grace Okonkwo".
  • Suspensions record the reason after a dash.

Hidden headers on phones

.ft-table__wrap is position: relative as well as overflow-x: auto, so the visually hidden caption and action-column headers stay inside the scrolling frame instead of widening the page at 375px (L2-045 AC1).
