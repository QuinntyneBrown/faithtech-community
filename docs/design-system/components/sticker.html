Estimate card

A small round card at the end of a row in the Planning Poker votes list. Before the reveal it shows only whether someone has voted (✓ or …); after the reveal it shows their points. Its class is .estimate-card.

Overview

Use the estimate card to show one person’s vote in a planning-poker session. It is read-only; voting happens in the estimate card picker. It always sits in a list row next to the person’s avatar and name, so the card carries only the value.

Anatomy

  1. CircleAccent-subtle background, --radius-full, sized by --estimate-card-size.
  2. ValueThe points, or ✓ / … before the reveal.
  3. Namerole="img" with an aria-label that says who and what: "Grace Okonkwo: 8 points".

Variants

✓ … 8 13 ?
  • Voted (✓) and still choosing (…) before the reveal, so nobody is anchored by another vote.
  • Points after the reveal, including "?" for Unsure.

Sizes

8 8

The votes list uses the default size (--size-avatar-md). .estimate-card--lg is for a summary such as "Marcus set 8 points". There are no other sizes; the inherited --xl, --bob and picture overlay were removed.

States

StateExample
Hidden: still choosing…
Hidden: voted✓
Revealed13

The card is not interactive, so it has no hover, focus, active or disabled state. Loading, error and empty belong to the Planning Poker page, which replaces the whole session.

Responsive behaviour

The card has a fixed size and never shrinks (flex: none); the name in the row truncates first. On phones the votes list stacks below the picker.

Role tokens only: --color-accent-subtle behind default text.

Accessibility

  • role="img" with a full aria-label, "Hannah Kim: 5 points", so ✓ and … are never read as raw symbols.
  • The value is text, so it never relies on colour. Text on --color-accent-subtle passes AA in both themes.
  • Votes revealing is announced once by the session alert ("Votes differ: 5 to 13"), not by each card.

Content

  • Labels: "Name: voted", "Name: still choosing", "Name: 8 points", "Name: unsure".
  • The heading over the list counts invitations: "Votes (5 invited)".
