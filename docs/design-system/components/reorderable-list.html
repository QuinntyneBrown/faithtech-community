Reorderable list

A list whose order is a setting: drag handle, move up and move down buttons, row actions or a row menu, and a polite announcement after every keyboard move.

WCAG 2.2 AAStatus: designed, not builtCDK drag and drop

Overview

A reorderable list is a list whose order is data: an organisation's chapters, partner stages, event types and resource types. Every row can be dragged by its handle or moved one place with its Move up and Move down buttons, and every keyboard move is announced in a polite live region (the L2-089 pattern used by the block editor). Row actions sit at the end: Rename and Archive as buttons, or a row menu when there are more.

  • Use it when the order of a short list (fewer than about 20 rows) is a setting other screens follow.
  • Don’t use it for sorting results; that is a sort control on a table.

Anatomy

  1. Drag handle.list__handle, decorative (aria-hidden); the buttons are the accessible way to move.
  2. Title and metaName and its count (“186 members”, “4 partners”).
  3. Move buttonsIcon buttons named “Move {name} up / down”; the first row's up and the last row's down are disabled.
  4. Row actions.list__actions: Rename and Archive, or a “More actions for {name}” menu.

Moved Vancouver up to position 2 of 3.

Just moved: .list__item--moved highlights the row, focus stays on its button, and the live region announces the new position (shown here; visually hidden in the product).
  • Disabled ends: the first row cannot move up and the last cannot move down.
  • Dragging: the handle shows cursor: grab; the CDK drop list draws its placeholder in the gap.
  • Saving: the order is saved after each move (PUT …/order); a failed save puts the row back and raises a danger toast with Try again.

Responsive behaviour

  • Below 40rem the row wraps: the actions move to a line of their own, indented under the title.
  • From 40rem the actions stay at the end of the row.

Theming

The moved row uses --color-accent-subtle with an inset --color-focus-ring in both themes; the handle uses --color-fg-subtle.

Accessibility

Role and pattern

A list (ul) named by its heading; drag and drop is an enhancement, never the only way (WCAG 2.5.7 Dragging movements).

Keyboard

KeyAction
TabMoves through each row's buttons.
Enter / Space on Move up or Move downMoves the row one place, keeps focus on the same button and announces “Moved {name} up to position {n} of {total}.”
Enter on More actionsOpens the row menu (menu button pattern).

Motion

The highlight fades in; with reduced motion it appears at once.

Content

  • Counts use the noun of the list: “186 members”, “4 partners”, “2 events”.
  • The announcement names the row and the position: “Moved Hackathon up to position 2 of 5 event types.”
