QR code

A machine-readable square that opens a link on a phone. City Leads show it from My QR code so someone they meet can join FaithTech Community and connect with them.

WCAG 2.2 AAStatus: new

Overview

The QR code renders a URL as an SVG path (one path, currentColor) on a light plate. It is always dark on light, in both themes, because phone cameras read dark modules on a light ground most reliably; the plate is the quiet zone. The component encodes the value itself (error correction M); feature code passes only the text.

Anatomy

  1. Plate--color-code-plate, --space-4 padding (at least four modules: the quiet zone), --radius-md, hairline --color-border-default edge so it reads on a light page.
  2. ModulesOne SVG path in --color-code-module with shape-rendering="crispEdges"; scaled, never blurred.
  3. Caption (optional)--text-caption in --color-fg-muted: "Scan with a phone camera".

Variants

One variant. The encoded text changes, the look never does: no logo in the middle, no colours, no rounded modules, so every camera can read it.

Sizes

Three sizes set --qr-size: sm 8rem (lists, previews), md 12rem (default, the dialog) and lg 16rem (shown on a phone held up to someone). The downloaded image is drawn at 1024px with the same quiet zone.

States

Two states: ready, and busy while a new code is being made (the old plate fades to 40% so it cannot be scanned by mistake). A code that could not be made is not drawn; the dialog shows an alert instead.

Responsive behaviour

The plate never shrinks below sm and never scales with the viewport; in a bottom-sheet dialog on phones it stays 12rem, centred. It never overflows its container: at 360px a 12rem plate plus padding fits with margins to spare.

Theming

The plate and modules use --color-code-plate and --color-code-module, which the dark theme deliberately does not override. In dark mode the light plate sits on the dark surface like a printed card.

Accessibility

  • The SVG has role="img" and an aria-label that says what the code opens ("QR code for your connect link"). Alternative text is required; the component refuses to render without it.
  • The code is never the only way: the same link is always shown next to it as text, in a copy field.
  • Module contrast is 21:1 in both themes.

Content

  • Caption: "Scan with a phone camera".
  • Alt text names the destination, not the picture: "QR code for your connect link", never "QR code image".
