Photo gallery

A photo gallery shows saved photos with their descriptions and per-photo actions that open dialogs, for screens where editing happens one photo at a time.

Overview

Used for a contact's photos on the contact page (L2-068). Unlike the picture list, which edits descriptions inline inside a form, the gallery shows each description as text and offers Feature, Edit description and Delete; the page opens a dialog for the last two (no inline forms on pages). The page header of the section holds the count badge and an Add photos button that opens the add dialog.

Anatomy

  1. Thumbnail .photo-gallery__thumb: square, --radius-md, the featured one ringed in the accent with a Featured badge.
  2. Caption .photo-gallery__caption: the photo's description, which is also its alt.
  3. Actions .photo-gallery__actions: small ghost buttons, each named with the photo number for screen readers.

Variants

The mocks use the gallery only on the contact page. Profiles and the contact form edit photos in the picture list.

Sizes

Thumbnails fill an auto-fill column of at least 10rem. There is no size input.

Featured, a normal photo, and a photo saved while storage is down (a described placeholder and a status note, L2-071).
HTML
<ft-photo-gallery
  [photos]="photos"            <!-- { id, url, alt, featured, storing } -->
  (featured)="feature($event)"
  (describe)="openDescribeDialog($event)"
  (remove)="openDeleteDialog($event)" />
  • Empty: the section shows "No photos yet…" and the Add photos button.
  • Full (10 photos): Add photos is disabled with the reason as its description.

Responsive behaviour

An auto-fill grid of columns at least 10rem wide; one column on the narrowest phones. Actions wrap under the caption.

Theming

Thumbnails sit on --color-bg-subtle with --color-border-default; the featured ring is --color-accent. No new tokens.

Accessibility

A list of items; each image's alt is its description. Action buttons read "Feature photo 2", "Edit description of photo 2", "Delete photo 2". The storing note is a polite status. After a dialog closes, focus returns to the button that opened it; after a delete, to Add photos.

Content

Storing: "Saved. It shows here once it finishes storing." Empty: "No photos yet. Add one so you recognise {first name} next time. Only you can see them."
