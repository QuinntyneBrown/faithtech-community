Copy field

A read-only value with a Copy button beside it: the connect link under the QR code. Copying confirms itself in place and in a toast.

Overview

Use a copy field when people need a value elsewhere (a link to paste in a message). The input is read-only, so the whole value can be selected by hand too; the button copies it with one press.

Anatomy

  1. LabelA visible field__label, always.
  2. ValueA read-only text field in the mono family at --font-size-sm; long values end in an ellipsis but stay fully selectable.
  3. Copy buttonA secondary button with the copy icon.
  4. StatusA polite live region that says "Link copied to the clipboard."

Variants

One variant. The button label names what is copied: "Copy link".

Sizes

One size: the default 44px control height, so the input and button line up.

States

ThemeDefaultCopiedDisabled
Light
Link copied to the clipboard.
Dark
Link copied to the clipboard.

Copied lasts 2 seconds, then the label returns to "Copy link". Disabled is used while the value is being replaced (a new QR code). When the clipboard is refused, the text is selected so the person can copy it by hand, and the status says "Select the link and copy it."

Responsive behaviour

The input takes the remaining width and the button keeps its label at every width; at 360px the value is truncated with an ellipsis, never wrapped.

Theming

Inherits the text field and button theming; the status uses --color-success-fg.

Accessibility

  • The input is labelled and read-only (not disabled), so screen readers read it and keyboards can select it.
  • The button is a real <button>; after copying, its label changes to "Copied" and the live region announces the result once.
  • Focus stays on the button after copying.

Content

  • Button: "Copy link" → "Copied".
  • Status: "Link copied to the clipboard."
