Switch

One on or off choice with a short label, like "Email me announcements". A track and a thumb that springs across, built on a native checkbox.

WCAG 2.2 AAStatus: stablelabel.switch + input[type=checkbox]

Overview

Use a switch for one setting that is either on or off and is saved with the form it sits in. FaithTech uses three:

  • "Keep me signed in on this device" on sign in, on by default, read when Grace presses Sign in.
  • "Email me announcements" in Settings, the announcement email opt-out, read when she presses Save settings. A caption under it says account emails always arrive.
  • "Also send by email (respects each person’s opt-out)" on compose announcement, on by default, read when Hannah presses Send.

For a choice between several options use a radio group. A switch never needs its own Save button and never acts on its own.

Anatomy

  1. TrackThe checkbox itself, --size-icon-md tall and 1.75 times as wide, fully round. --color-border-strong when off, --color-accent when on.
  2. ThumbA --color-bg-surface circle with --shadow-1. It sits left when off and springs right when on.
  3. LabelA short statement in --text-body. An optional small line under it exists in the CSS but is not used; Settings puts its note in a caption after the switch instead.

Variants

There is one variant. It is off unless the page says otherwise.

You’ll always get account emails like password resets.

Sign in (on), Settings (off, with a caption after it) and compose announcement (on).
HTML
<label class="switch"><input type="checkbox" name="remember" checked><span class="switch__text">Keep me signed in on this device</span></label>
          <label class="switch"><input type="checkbox" name="n3"><span class="switch__text">Email me announcements</span></label><p class="text-caption">You’ll always get account emails like password resets.</p>
          <label class="switch"><input type="checkbox" name="email" checked><span class="switch__text">Also send by email (respects each person’s opt-out)</span></label>

Sizes

Not applicable. The switch has a single size at every width.

States

OffOnHoverFocusDisabled offDisabled on

Both themes

  • Hover darkens the off track to --color-fg-muted and the on track to --color-accent-hover.
  • Focus draws the shared focus ring around the track.
  • Disabled uses --color-border-default for the track and --color-fg-disabled for the label. No mock disables a switch; while a form submits, only its buttons lock.
  • There is no invalid state: either position is a valid answer.

Responsive behaviour

  • The switch does not change size with the viewport.
  • The track never shrinks (flex: none); a long label such as "Also send by email (respects each person’s opt-out)" wraps beside it.
  • The whole label row is the tap target, so it is easy to hit on a phone.

Theming

Every colour is a token, so the switch follows the theme with no overrides. The on track uses the accent, the off track uses the strong border colour, and the thumb uses the surface colour so it stays visible against both tracks in light and dark.

Accessibility

Role and pattern

This is a native checkbox styled as a switch (appearance: none). It follows the APG checkbox pattern, not the APG switch pattern. role="switch" is optional and is not used, so assistive technology says "Email me announcements, checked" or "not checked", which matches what the visual shows.

Keyboard

KeyAction
TabMoves focus to the switch. A disabled switch is skipped.
SpaceToggles the switch.

Focus

The shared focus ring on :focus-visible, offset from the track so it never touches the thumb.

Labelling

The visible text is the accessible name because the input sits inside its label. No aria-label is needed. A related caption (Settings) should be joined with aria-describedby.

Contrast

Track on vs surface
Track off vs surface
Thumb vs track on
Focus ring vs surface

Motion

The thumb springs across with --ease-spring over --duration-base, and the track colour fades with --ease-standard. Reduced motion zeroes both durations, so the thumb jumps.

Touch

The label row is at least --target-min tall, and tapping the label text toggles the switch.

Content

  • The label says what happens when it is on, as a statement: "Keep me signed in on this device", "Email me announcements".
  • Put a short qualifier in brackets in the label only when it changes the meaning: "(respects each person’s opt-out)".
  • A switch is on by default only where the page says so: sign in and the announcement email are; the Settings opt-out reflects the saved value.
