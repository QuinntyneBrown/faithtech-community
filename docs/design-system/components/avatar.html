Component · Identity

Avatar

A circle with a person's photo, laid over their initials on their colour. It sits beside every name in FaithTech Community: Grace Okonkwo's photo (over "GO" in sky) in the top bar, rows in Contacts and Team, activity feeds, the admin tables, and extra large at the head of a profile.

Overview

Use an avatar wherever a row, card or header is about one person: a member, a private contact or whoever did something in a feed. It always sits next to the printed name, so it helps scanning; it is never the name itself.

  • Static (span.avatar, aria-hidden="true"): beside a name in lists, feeds, tables and the profile head.
  • Trigger (button.avatar-trigger around a small avatar): the last item in the top bar, opening the account menu.
  • Plain (no colour modifier): private contacts who have not signed up, such as Abby Brooks and Kwame Asante, and suspended accounts such as Victor Kane. They show a photo like everyone else; the plain colour is only what shows behind it.
  • In Angular, use <ft-avatar> from the components library and pass [color]="avatarColorFor(profileId)" for a member; leave the colour unset (plain) for an unlinked contact or a suspended account.

Every avatar shows the person’s photo, a member’s featured photo for instance, as on the team list (.avatar__img, alt="", initials stay behind it as the fallback). Do not use an avatar for status (use a badge) or for a partner organisation.

Anatomy

  1. InitialsFirst and last initial, two capitals ("SM"), in --text-label, --color-fg-on-cover on a colour.
  2. Circle--radius-full, sized by --avatar-size, filled with the person's colour.

Variants

Seven colours (sky, sun, lilac, sage, rose, mint, peach) plus the plain accent tint. A person keeps one colour on every screen: the colour is not picked per screen but derived from the member's profile id (avatarColorFor(profileId) in the components library, ADR 0008), so every screen that shows them computes the same one. With seven colours, people share colours (Marcus Lee and Tomás Ortega are both sun); the printed name, never the colour, tells them apart. The cast's colours are listed in docs/mocks/README.md.

Avatar trigger

The top-bar account menu button. .avatar-trigger removes the underline and gives the avatar inside a hover ring. In the Angular component the trigger draws its initials with CSS (data-initials), so the button’s only text is its label (WCAG 2.5.3, label in name).
HTML
<button class="avatar-trigger" type="button" aria-haspopup="menu" aria-label="Account menu for Grace Okonkwo">
  <span class="avatar avatar--sm avatar--sky" aria-hidden="true">GO</span>
</button>

Sizes

The mocks use two sizes: small wherever a name sits in a row, and extra large at the head of a profile. Medium and large exist in the CSS but no FaithTech mock uses them.

Both themes

GOSMAB
GOSMAB
  • Hover draws a 2px ring in --color-border-strong around the avatar.
  • Focus uses the shared focus ring on the round link.
  • There is no disabled or selected avatar.

Responsive behaviour

  • Sizes do not change with the viewport; the top-bar trigger is small at every width.
  • The avatar never shrinks in a flex row (flex: none), so a long name or meta line wraps beside it.
  • On a phone the profile head wraps and the extra-large avatar sits above the name.

Theming

Person colours read the pastel --color-cover-* tokens (names inherited from Shelfie) with --color-fg-on-cover initials, which stay dark in both themes. The plain avatar uses --color-accent-subtle and --color-fg-accent and follows the theme.

Accessibility

Role and pattern

Static avatars are <span aria-hidden="true"> because the name is always printed beside them. The trigger is a native <a> to the signed-in member's profile.

Content

  • Initials are the first letters of the first and last name, in capitals: "GO" for Grace Okonkwo, "TO" for Tomás Ortega.
  • A private contact gets initials the same way ("AB" for Abby Brooks) on the plain avatar, behind their photo.
  • The trigger's label says what it opens and whose it is: "Account menu for Grace Okonkwo".
