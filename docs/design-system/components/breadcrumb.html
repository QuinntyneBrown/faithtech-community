Breadcrumb

A short trail above the page title that says where you are and takes you back up: "Contacts / Archived contacts", "Workspaces / Toronto team / Shelter problem briefs for teams".

WCAG 2.2 AAStatus: stableNative <nav> + <ol>

Overview

Use a breadcrumb at the top of main on every page that sits under another: a contact, new or edit contact, archived contacts, an event, new or edit event, a partner, edit profile, new announcement, invites, a workspace board or backlog, and a work item. FaithTech Community is at most three levels deep, so a trail has two or three items: the ancestors (links) and this page (plain text). Work items go through their workspace: Workspaces / Toronto team / Shelter problem briefs for teams. Top-level pages (Home, Events, Contacts, Partners, Workspaces, Team, Announcements, People) have no breadcrumb.

A breadcrumb is not the main way around; the top bar and tab bar are. It is the quick "back" that survives a page reload.

Anatomy

  1. Parent linkAn <a> in --color-fg-muted, no underline until hover.
  2. SeparatorA "/" drawn by CSS (li + li::before) in --color-fg-subtle; not read aloud.
  3. Current pagePlain text in --color-fg-default, medium weight, with aria-current="page".

HTML
<nav aria-label="Breadcrumb">
  <ol class="breadcrumb">
    <li><a href="/contacts">Contacts</a></li>
    <li aria-current="page">Archived contacts</li>
  </ol>
</nav>

Sizes

One size, --text-body-sm with --space-2 between items.

  • Hover darkens the link to --color-fg-default and underlines it, so it reads as a link even though it rests without an underline.

Responsive behaviour

  • The list wraps (flex-wrap). A long current title ("Shelter problem briefs for teams") drops to a second line at 360px instead of truncating, so the full name is always visible.
  • No collapsing or "…" items: trails are never longer than three, and a three-item trail wraps cleanly at 360px.

Theming

Three text tokens and nothing else: --color-fg-muted for links, --color-fg-default for hover and the current page, --color-fg-subtle for separators. Each is defined for both themes, so the trail sits on --color-bg-canvas in either.

Accessibility

Role and pattern

The WAI-ARIA APG Breadcrumb pattern: <nav aria-label="Breadcrumb"> containing an ordered list; the last item has aria-current="page". Separators are CSS generated content, so they are not announced.

Keyboard

KeyAction
Tab / Shift+TabMoves through the ancestor links in order. The current page is text, not a tab stop.
EnterFollows the parent link.

Focus

The shared 2px --color-focus-ring with 2px offset around the link.

Labelling

The landmark is labelled "Breadcrumb" so it is distinct from the "Primary" nav. Link text is the parent page's name exactly as its own heading says it.

Contrast

Link on canvas
Current page on canvas
Separator on canvas
Focus ring on canvas

Motion

None.

Touch

The link is text in --text-body-sm; it is at least --target-min (24px) tall, so it meets the WCAG 2.2 minimum target size. It is a secondary route: the brand in the top bar and the tab bar are the 44px targets for the same destinations.

Content

  • Each ancestor is named as its page heading: "Contacts", "Events", "Partners", "Workspaces", "People and roles", "Profile", or the workspace name ("Toronto team").
  • The current item repeats this page's subject: the record name ("Tomás Ortega", "Kestrel Labs", "Toronto Builders Night") or the task ("New contact", "Edit event", "New announcement").
  • Once the record is known the current item is always its name, in every state that shows the record (default, lead, staff, member, cancelled, empty). Only while the record is still loading, when its name is not yet known, does the current item fall back to the record type, matching the page heading: "Contact", "Partner", "Event" or "Story" (see pages/event/loading). Error, not-found and forbidden states drop the trail.
  • Never "Home" or "Back".

<main id="main" class="container">
  <nav aria-label="Breadcrumb">
    <ol class="breadcrumb">
      <li><a href="/workspaces">Workspaces</a></li>
      <li><a href="/workspaces/toronto-team">Toronto team</a></li>
      <li aria-current="page">Shelter problem briefs for teams</li>
    </ol>
  </nav>
  <div class="page-header"> … </div>
</main>
Class / attributeEffect
.breadcrumbOn the <ol>: wrapping row, small muted text, "/" separators.
aria-current="page"On the last <li>: default colour, medium weight.
data-state="hover|focus"Documentation only: forces a link state.
