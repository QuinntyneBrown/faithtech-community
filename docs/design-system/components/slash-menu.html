Slash menu

A filterable list attached to the caret in a block: "Insert a block" when the owner types /, and "Link to a page" when they type [[. One component, two option sets.

Overview

The slash menu lets the owner insert or change a block without leaving the keyboard, and the same list, fed with pages, inserts a page link. Focus stays in the block's text box the whole time: the text box is the combobox, the list is its popup and the active option is exposed with aria-activedescendant. It is part of the block editor and is never used on its own.

  • Insert a block: opens on / at the start of a block or after a space, lists every block type with a one-line description and its markdown shortcut, and filters by type name as the owner types.
  • Link to a page: opens on [[ in any text block except Code and lists up to 10 non-archived pages the owner may open, most recently edited first, filtered by title (GET /api/notes/links?q=&exclude={id}).
  • Do not use it for choosing a value in a form (use a select or the person picker) or for actions on a block (use the block menu).

Anatomy

  1. Group label.slash-menu__group, overline type, role="presentation": "Basic blocks", "Media". Not an option.
  2. Active option.slash-menu__item[aria-selected="true"]: accent-subtle fill and an inset focus ring, since DOM focus stays in the text.
  3. Icon.slash-menu__icon: a 32px tile with the type's glyph (Aa, H1, •, 1., ☐, ❝, 💡, </>, —) or the page's emoji. Decorative.
  4. Title and hint.slash-menu__title (label) and .slash-menu__hint (caption, muted): the type's description, or the page's owner and place.
  5. Shortcut.slash-menu__shortcut: the markdown that makes the type ("# ", "- ", "[] "), in code type. Insert a block only.
  6. Footer.slash-menu__footer: the keys, or the count of pages listed. aria-hidden is not needed; it is plain text after the list.

      Responsive behaviour

      • Anchored below the caret's block, starting at the text column (CDK Overlay with a flexible position strategy). Near the bottom of the viewport it flips above the block; it never leaves the viewport.
      • Below 640px it spans the editor's width (left: 0; width: 100%); options keep their 32px height.
      • The list scrolls inside the panel past 22rem; the active option is kept in view as ↑ / ↓ move.
      • On a phone the on-screen keyboard stays up, since focus never leaves the text box.

      Theming

      The panel is a raised surface (--color-bg-surface-raised, --color-border-default, --shadow-3), like the menu. Hover is --color-bg-subtle; the active option is --color-accent-subtle with the --color-focus-ring inset outline. Icon tiles sit on --color-bg-surface; shortcuts on --color-bg-subtle in --color-fg-muted. In dark the raised panel is lighter than the page so it reads as above it without the shadow.

      Accessibility

      Role and pattern

      WAI-ARIA APG Combobox with a listbox popup, where the block's text box is the combobox. The text box gets aria-controls (the list), aria-expanded, aria-autocomplete="list" and aria-activedescendant (the active option's id). The list is role="listbox" named "Insert a block" or "Link to a page"; options are role="option" with aria-selected on the active one; group labels are role="presentation". DOM focus never leaves the text box (L2-099 AC3).

      Keyboard

      KeyAction
      /At the start of a block or after a space: opens Insert a block with the first option active.
      [[In a text block other than Code: opens Link to a page.
      TypingFilters the options by type name or page title; the first match becomes active.
      ↓ / ↑Moves the active option, wrapping at the ends; group labels are skipped.
      EnterChooses the active option: turns or inserts the block, or inserts the page link; the command text is removed and the caret moves into the block.
      EscCloses the menu, keeps the typed text and returns the caret to where it was.
      Backspace past the / or [[Closes the menu.
      TabCloses the menu and moves focus on as usual; nothing is chosen.

      Focus

      The active option shows the accent-subtle fill plus the 2px focus ring inside its edge, because the real focus ring stays on the text box. Pointer hover does not change the active option until a click.

      Labelling and announcements

      Each option's accessible name is its title, then its hint ("Heading 1, A big section heading."). Icons are aria-hidden; the shortcut is plain text read after the hint. "No matching blocks" and "No pages match “{term}”" are announced through the footer's role="status". Page titles are only ever pages the owner may open (L2-090 AC7).

      Motion

      The panel scales in from the top left over --duration-fast with --ease-enter; reduced motion zeroes the duration.

      Touch

      Options are 32px tall and full width; a tap chooses. Typing / works on a phone keyboard; there is no separate "+" button in v1.

      Content

      • List names: "Insert a block" and "Link to a page".
      • Type names and descriptions come from BLOCK_TYPES; descriptions are short sentences ending in a full stop.
      • Page hints: "{owner} · {visibility or place}", with "You" for the owner's own pages ("You · inside Toronto city team playbook").
      • Empty results: "No matching blocks" and "No pages match “{term}”" with curly quotes.
      • Footer: "↑↓ to move · Enter to insert · Esc to keep typing", or "{n} pages you can open · Enter to link · Esc to keep typing".
