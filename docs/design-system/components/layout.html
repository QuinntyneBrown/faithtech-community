Layout primitives

A small set of classes that place everything else: the page container, vertical stacks, wrapping rows, the column grid, the two-to-one split, the page header and the centred auth card.

WCAG 2.2 AAStatus: stableCSS only, no ARIA

Overview

Compose pages from these primitives instead of writing layout CSS. They read the layout tokens (--layout-columns, --layout-gutter, --layout-margin), which change at 768px and 1024px, so pages respond without their own media queries. Most are inherited from Shelfie; .split is FaithTech's own.

  • .container: the page width (max 1280px) and side margins. main on every signed-in page.
  • .stack: children in a column, 16px apart. Cards, forms, dialog bodies.
  • .cluster: children in a wrapping row, 12px apart, vertically centred. Button rows, role badges, stats. .cluster--between pushes the ends apart (a card title with an "Open board" link). .cluster--tight closes the gap to 4px for a run of role badges in a list row's meta line (<ft-cluster gap="1"> in Angular).
  • .grid: the token column grid; a form can set --layout-columns: 2 for a Starts/Ends pair. .grid--auto fills with 18rem-minimum cards instead.
  • .split: one column on phones, main and aside at 2:1 from 1024px. Home, event, contact and partner pages.
  • .page-header (title, subtitle, actions) and .section (vertical rhythm between page sections).
  • .auth-layout + .auth-card: the centred card on sign in, sign up, accept invite, verify email, forgot and reset password, with the logo mark above it.

Anatomy

Home for Grace Okonkwo, the page that uses the most primitives at once.

  1. Containermain.container: max --layout-container-max, side padding --layout-margin.
  2. Page header.page-header: title block on the left, actions on the right ("New event", "Add contact"), wraps on phones. The subtitle is plain text or, as on the partner page, rich content such as a stage badge (ftPageHeaderSubtitle in code).
  3. Split.split: one column, then 2fr / 1fr from 1024px, --layout-gutter apart.
  4. Main columnA .stack of cards.
  5. Aside<aside class="stack" aria-label="Activity">: under the main column on phones.

The anatomy figure forces two columns so it reads at any window width; real pages let .split choose.

Sizes

Primitives have no size modifiers; gaps and widths come from the spacing and layout tokens listed below.

States

Layout primitives are not interactive and have no states; the only change is responsive (see below). Loading pages mark the busy region with aria-busy="true" on the .grid or card, not on the primitive itself.

Responsive behaviour

WidthColumnsGutterMarginSplit
Base (phones)4--space-4 (16px)--space-4 (16px)One column; aside under main.
768px (--layout-breakpoint-md)8--space-6 (24px)--space-8 (32px)Still one column.
1024px (--layout-breakpoint-lg)12--space-8 (32px)--space-12 (48px)2fr / 1fr.
  • Mobile first: base styles target 360px and only min-width queries add space.
  • .page-header wraps: on phones the actions drop under the title. .cluster wraps its children; nothing scrolls sideways at 320px.
  • On phones .has-tabbar on body reserves space for the tab bar under the container.

Theming

Primitives draw no colour; layout tokens change by breakpoint, not by theme.

Accessibility

Role and pattern

No roles of their own. Put them on the right native element: .container on <main id="main">, the split's aside on <aside aria-label> or a <section aria-labelledby>, .auth-layout on <main>.

Keyboard

KeyAction
Tab / Shift+TabFollows DOM order. Primitives add no tab stops; never reorder columns visually with order or grid-row, so focus order matches reading order (main before aside).

Focus

html has scroll-padding-top equal to the top bar plus --space-4, and .has-tabbar reserves the tab bar, so focused content is never hidden under sticky bars.

Labelling

The page header holds the page's only <h1>. On auth pages the <h1> sits in the auth card. Sections and asides are named by their visible heading or an aria-label.

Contrast

Primitives draw no colour. Text in .page-header .subtitle uses --color-fg-muted:

Subtitle on canvas
Page title on canvas

Motion

None. html uses smooth scrolling for in-page links, turned off under prefers-reduced-motion.

Touch

.cluster puts 12px between neighbours, above the spacing needed for 24px targets. Content reflows at 320px CSS width (WCAG 1.4.10).

Content

  • Page header: the title says where you are ("Good afternoon, Grace", "Partners", "Samuel Mensah"); the subtitle gives today's context ("Tuesday 21 October · 3 events coming up").
  • Keep page header actions to the page's main tasks, primary first ("New event", then "Add contact").

Drift noticed in the mocks:

  • Inline spacing on layout wrappers: .split with style="margin-top: var(--space-4);" on Home, a profile card with margin-top: var(--space-6).
  • The two-column form grid overrides --layout-columns: 2 inline in four event-form mocks; it should be a named modifier.
  • Auth pages centre text with inline style="text-align: center;" on the heading and footer links.
  • Loading skeletons size themselves inline (style="width: 12rem; display: inline-block;", style="flex:1;").
