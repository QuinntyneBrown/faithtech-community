Component · Identity

Logo mark

The FaithTech mark as its own tile: a violet rounded square with a white cross inside a faint ring. It sits centred above the card on every sign-in style screen.

Overview

Use the logo mark only on the auth pages: sign in, sign up, verify email, accept invite, forgot password and reset password. It goes above the card, once per page, and it is the only place on those pages that says the screen belongs to FaithTech Community.

The signed-in top bar does not use it; it shows a plain brand link, described on the top bar page. Never use the mark as an avatar for a person, partner or workspace.

Anatomy

  1. TileA grid box that centres the image, sized by --size-avatar-xl, with --radius-lg corners and clipped overflow.
  2. Imagelogo.svg, a 64 by 64 vector, scaled to fill the tile with object-fit: contain. Being vector, it stays sharp on high-density screens.
  3. Shadow--shadow-2 lifts the tile off the page so it reads as an app icon, not a flat picture.

Variants

Not applicable: there is one logo mark, wrapped in .logo on the auth card. The FaithTech mocks do not animate it.

Exactly as it appears above the Sign in card.
HTML
<div class="logo"><span class="logo-mark"><img src="../../assets/logo.svg" alt="FaithTech" width="64" height="64"></span></div>

Sizes

The tile is fixed at 64px, which is --size-avatar-xl. It has no small or large form.

States

Not applicable: the logo mark cannot be focused, hovered, disabled or loading. It looks the same on the default, busy, error, locked and suspended sign-in states.

Responsive behaviour

  • The tile stays 64px at every width; it does not scale with the screen.
  • .auth-card .logo centres it in the card column from phone to desktop, with --space-6 below it.

Theming

The SVG carries its own brand violet and white, so the artwork is identical in light and dark. Only the shadow changes, because --shadow-2 is redefined per theme. If FaithTech supplies brand colours, replace logo.svg; no token change is needed.

Accessibility

Role and pattern

An image with alt="FaithTech", as the mocks use. On auth pages there is no other brand name, so the mark identifies the site; the page <h1> ("Sign in", "Create your account") then names the screen. If a visible "FaithTech Community" heading is ever added next to it, switch to alt="" so the name is not read twice.

Keyboard and focus

Not interactive and never in the tab order. It is not a link home; auth pages have no home to return to.

Contrast

The white cross on violet is a graphical object, well above 3:1. The tile edge relies on the shadow and is decorative.

Motion

None.

Content

  • Never put text inside the tile or a caption over it.
  • Never redraw the mark with an icon or emoji; always use logo.svg.
  • Alt text is the organisation name only: "FaithTech", not "FaithTech logo".
