Emoji picker

Chooses one emoji as an icon: a Notes page's icon in Page settings, or a callout's icon in Change icon. It is a radio group of 16 emoji tiles, each named for screen readers, with an optional "No icon" first.

Overview

Use the emoji picker when a member gives something a small visual mark from a fixed, curated set. Today that is a page's icon (shown in Notes, in search, in breadcrumbs and wherever the page is linked) and a callout block's icon. The set is fixed so every icon has a name a screen reader can read; there is no free emoji input.

For choosing among words, use a radio group. For a page's visibility, use the share dialog's radio group, not icons.

Anatomy

  1. Legend"Icon" by default (legend input); names the role="radiogroup" fieldset.
  2. No iconA text radio, first, when allowNone is true. Chooses null.
  3. Grid.emoji-grid: tiles of at least 48px that wrap to the width.
  4. Tile.swatch: a native radio named by the emoji's name ("Blue book") with the emoji drawn over it, aria-hidden. The name is also the tile's title.
  5. Chosen markAccent-subtle fill and accent border on the checked tile.

Variants

Page icon, with "No icon"

Icon
Page settings (dialogs/note-settings). A page may have no icon; lists then show the default page glyph.

Callout icon, without "No icon"

Icon
Change icon (dialogs/change-icon, [allowNone]="false"). A callout always has an icon; it starts as 💡.

Sizes

One size. Tiles are at least --space-12 wide, square, with the emoji at --font-size-2xl; the grid fills the dialog's width.

States

StateExample
Default
Hover
Focus
Checked
Disabled
No icon chosen
  • There is no invalid state: a choice is always valid. With allowNone false the picker should be given a value (the callout's current icon, or 💡).
  • Disabled comes from the form control (setDisabledState) and disables the whole fieldset.
  • Saving belongs to the page: both dialogs close on Save and the page's autosave stores the choice.

Responsive behaviour

  • The grid uses auto-fill: about eight tiles a row in a desktop dialog, five at 360px in the full-screen sheet. Nothing scrolls sideways.
  • Tiles keep at least the 44px comfortable target at every width.

Theming

Icon
Icon

Role tokens only. In forced-colours mode tiles keep a system border, and the checked tile is still exposed by the radio's checked state.

Accessibility

Role and pattern

WAI-ARIA APG Radio Group built from native radios: a <fieldset role="radiogroup"> named by its <legend>, every radio sharing one generated name. Each emoji radio's accessible name is the emoji's name ("Light bulb"), never the emoji glyph, which is aria-hidden.

Motion and touch

Only the border colour transitions, and not under prefers-reduced-motion. Every tile meets the 44px target.

Content

  • Legend "Icon". The empty choice reads "No icon" (pages only).
  • The 16 emoji and their names: 📘 Blue book, 📝 Memo, 📋 Clipboard, ✅ Check mark, 🛠️ Hammer and wrench, 💡 Light bulb, 🧭 Compass, 📅 Calendar, 🤝 Handshake, 🎯 Target, 🚀 Rocket, 🙏 Folded hands, ⚠️ Warning, 📣 Megaphone, 🏙️ City, 💻 Laptop.
  • Names are plain nouns in sentence case; they are what screen-reader users hear and what shows on hover.

Code

<!-- Angular (components library): a ControlValueAccessor; the value is the emoji or null -->
<ft-emoji-picker legend="Icon" [formControl]="icon" />                       <!-- Page settings: "No icon" first -->
<ft-emoji-picker legend="Icon" [allowNone]="false" [formControl]="icon" />   <!-- Change icon (callout) -->
// inputs: legend = 'Icon', allowNone = true
// PAGE_ICONS: readonly { emoji, name }[] — the 16 icons and their names, exported for reuse

<!-- HTML -->
<fieldset class="stack" role="radiogroup"><legend class="field__label">Icon</legend>
  <label class="choice"><input type="radio" name="icon"><span class="choice__text">No icon</span></label>
  <div class="emoji-grid">
    <label class="swatch" title="Blue book"><input type="radio" name="icon" aria-label="Blue book" checked><span aria-hidden="true">📘</span></label>
    …
  </div>
</fieldset>
Class / inputEffect
.emoji-gridWrapping grid of square tiles.
.emoji-grid .swatchOne tile; input:checked (or [data-state="checked"]) is the chosen mark, [data-state="hover|focus"] show those states statically.
legend, allowNoneThe group's name, and whether "No icon" is offered first.
Form valueThe emoji string, or null for no icon. The built component uses .ft-emoji-picker, __legend, __grid, __choice and __choice--none.
