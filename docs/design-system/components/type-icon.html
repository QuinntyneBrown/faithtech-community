Type icon

The resource type shown at a glance: an icon in an icon tile for every type, or the image itself in a thumbnail tile for an Image resource. On a resource page the same choice fills the file preview.

WCAG 2.2 AAStatus: newft-icon-tile

Overview

Use type icons wherever a resource is listed (Resources, Archived, global search, file rows) and the file preview at the top of a resource page. They extend the existing IconTileComponent (ft-icon-tile) and IconComponent; there is no separate component. Only uploaded PNG, JPEG, GIF and WebP images get a thumbnail; SVG logos are shown as an image tile of the file itself where the mock does, and every deck, PDF or document shows its type icon (no rendered page previews).

Anatomy

  1. Icon tile.icon-tile, 40px (--size-avatar-md), --radius-md, --color-accent-subtle, the type's stroke icon in --color-fg-accent. Decorative: the type is in the meta line.
  2. Image tile.icon-tile--image: the thumbnail with object-fit: cover on --color-bg-subtle with a hairline border. Decorative in lists.
  3. Link markerThe external icon (icon--sm) before the host in the meta line.

States

Type icons are not interactive; the row or page around them owns hover and focus. They have three content states.

StateExample
Type icon
Thumbnail
File not stored yet An image whose file is still being stored shows its type icon until the thumbnail exists.

Both themes

Responsive behaviour

  • Tiles never shrink (flex: none).
  • At XS the file preview spans the width and the image scales down to fit, at most 20rem tall.

Theming

Tiles read --color-accent-subtle and --color-fg-accent; image tiles --color-bg-subtle and --color-border-default; the preview --color-bg-subtle.

Accessibility

Labelling

In lists the tile is aria-hidden and the type is spoken from the meta line ("Deck · PPTX · 24.6 MB"). The thumbnail in a list has empty alt text for the same reason. On a resource page the preview image carries the alt text the owner supplied; a type-icon preview is decorative and the file name and meta beside it are text.

Colour

Content

  • The meta line always spells the type: "Deck · PPTX · 24.6 MB" or "Template · docs.google.com".
  • Alt text for an image preview describes the image, not the file ("The FaithTech mark: …").
